## What MDX gives you

Markdown plus components. Headings, lists, links, and code all render through
the site's `prose` styles:

- Ordinary Markdown syntax
- [Links](https://nielsbik.nl) styled like the rest of the site
- Fenced code blocks with syntax highlighting
